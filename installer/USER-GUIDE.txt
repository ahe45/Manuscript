Manuscript Windows 오프라인 설치본

1. 설치 파일을 실행하고 바탕화면 또는 시작 메뉴에서 Manuscript를 엽니다.
2. 처음 실행하면 내장 데이터베이스를 준비하고 원고지 로그인 화면을 엽니다.
3. 답안은 자동 저장됩니다. PDF 또는 ZIP을 다운로드하려면 PC에 Google Chrome이 설치되어 있어야 합니다.
4. 작업이 끝나면 저장 상태를 확인한 뒤 실행 관리 창의 서버 종료를 누릅니다.
5. 실행 관리 창에서 DB 백업, 복원, 백업 폴더 열기를 할 수 있습니다.
   복원 시 현재 데이터를 먼저 백업하며, 복원이 끝나면 원고지에 다시 로그인합니다.

데이터는 현재 Windows 사용자의 LocalAppData 아래 Manuscript\data에 저장됩니다.
프로그램 업데이트 또는 제거 후에도 사용자 데이터 폴더를 보관합니다.
실행이 실패하면 해당 폴더의 runtime.log를 확인하세요.
